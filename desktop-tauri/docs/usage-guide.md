# 使用说明

## 简介

Steam 家庭库分析器是一个桌面工具，帮助你分析 Steam 账号的公开游戏库能给家庭库带来多少**新游戏**和**价值**。

输入一个或多个目标 Steam 账号，工具会自动比对你的家庭共享库，列出新增游戏、重复游戏并估算对应价值。

## 安装

从 [Releases](https://github.com/anomalyco/steam-family-fit-analyzer/releases) 页面下载最新 `Steam 家庭库分析器_x.x.x_x64-setup.exe`，双击安装。

> **Windows SmartScreen 提示**：由于应用未经过微软代码签名，首次运行可能会弹出 SmartScreen 警告。点击「更多信息」→「仍要运行」即可。

## 首次配置

安装后打开应用，进入「配置」页完成以下设置：

### 1. Steam Web API Key

在 [Steam 开发者页面](https://steamcommunity.com/dev/apikey) 注册获取。首次注册可填任意域名（如 `localhost`）。

### 2. 当前 SteamID64

你的 Steam 账号 17 位数字 ID。可在 Steam 客户端「帐户明细」页面查看，或点击「前往获取」按钮自动获取。

### 3. 家庭库 Access Token

- 点击「前往获取」按钮，会自动打开 Steam 家庭管理页面并将一次性脚本复制到剪贴板。
- 在已登录的 Steam 页面地址栏粘贴脚本并回车执行。
- Token 会在约 5 分钟后过期，过期需重新获取。

### 4. IsThereAnyDeal API Key（可选）

如需查看游戏**史低价格**，在 [ITAD 设置页](https://isthereanydeal.com/settings/web-api/) 注册获取。不需要史低价格可跳过。

### 5. 地区和语言

- 地区：默认为 `CN`，影响商店价格币种。
- 语言：默认为「自动」（跟随系统），可手动切换中/英文。

> 所有配置保存在你的电脑本地，不会上传到任何服务器。

## 运行分析

1. 切换到「分析」页。
2. 在文本框输入目标 Steam 账号，支持以下格式（每行一个）：
   - 17 位 SteamID64：`76561198012345678`
   - 好友码：`123456789`
   - 个人主页 URL：`https://steamcommunity.com/id/xxx`
   - 自定义 ID：`xxx`
3. 点击「开始分析」。
4. 等待几秒到几十秒（取决于目标游戏库大小），即可看到分析结果。

> 分析结果**不会**自动保存。关闭页面或重新分析后结果会被替换。

## 阅读结果

### 摘要栏

顶部显示本次分析的统计指标：

- **家庭库游戏数**：当前家庭库中的游戏总数。
- **新增**：目标账号有、但家庭库没有的游戏数。
- **新增价值**：新增游戏的商店价格总和。
- **重复**：目标账号和家庭库都有的游戏数。
- **重复率**：重复游戏占目标公开游戏库的比例。

鼠标悬停指标可查看按目标账号拆分的详细信息。

### 列表标签页

- **全部**：目标账号的所有公开游戏。
- **新增**：家庭库中没有的游戏（核心关注）。
- **相对新增**：家庭库中没有，且当前账号未拥有的游戏。
- **重复**：家庭库中已存在的游戏。

### 视图切换

点击右上角图标可在「封面视图」和「列表视图」之间切换。列表视图支持排序和搜索。

### 快捷操作

右上角「更多」菜单提供：

- **复制分析报告**：复制完整的文字摘要。
- **复制列表**：复制当前标签页的游戏名（Tab 分隔）。
- **复制游戏名**：复制当前标签页的游戏名（换行分隔）。
- **保存封面图**：将当前列表的游戏封面导出为 PNG 海报。

## 封面图导出

在「保存封面图」弹窗中可调整：

- **每行列数**：控制海报中游戏封面的列数（1-50）。
- **排序方式**：按名称、商店价格、史低价格等排序。
- **尺寸缩放**：控制封面缩略图大小（40%-100%）。

调整后点击「生成图片」选择保存路径。

## 配置备份

在配置页的「配置备份」区域：

- **导出设置**：将当前所有配置（含 API Key）保存为 JSON 文件，便于备份或迁移。
- **导入设置**：从之前导出的 JSON 文件恢复配置。

> 导出的配置文件包含 API Key 等敏感信息，请妥善保管。

## 缓存管理

应用会自动缓存以下数据以加速后续分析：

- 游戏商店信息（名称、封面、家庭共享支持性）
- 价格数据（原价、史低）
- 封面图片文件

缓存在配置页「缓存目录」区域管理：

- **前往目录**：在文件管理器打开缓存目录。
- **修改路径**：更换缓存目录位置。
- **恢复默认**：恢复为系统默认缓存路径。
- **清除缓存**：删除所有缓存文件。

> 缓存数据保留 7 天后自动过期。目标账号的游戏库不会被缓存，每次分析都会重新请求以确保结果准确。

## 常见问题

**Q: 分析失败提示「access token 无效」？**

A: 家庭库 Access Token 约 5 分钟后过期，请重新点击「前往获取」按钮获取新 Token。

**Q: 价格显示「暂无」或为 0？**

A: 检查商店地区设置是否与你 Steam 账号的地区一致。部分游戏可能没有标价（如未发售、已下架）。

**Q: 史低价格不显示？**

A: 需要在配置页填写 IsThereAnyDeal API Key，并将价格口径切换为「史低价」。

**Q: 封面图加载失败？**

A: 尝试右键点击游戏封面选择「刷新封面」，或清除缓存后重新分析。
